# OpenAIO

Open-source 25.5×25.5 mounting-pattern AIO (flight controller + 4-in-1 ESC + ExpressLRS receiver) for toothpick-class 6S FPV drones. Target: ~30 A continuous per motor at 6S, digital (HD) video.

Built from three proven sibling designs in the OpenDrone family:

| Stage | Source design | Status of source |
|---|---|---|
| FC | **OpenFC-Lite-Mini** rev 2 (RP2354A) | Rev 2 ordered |
| ESC | **4in1-mini** Rev 2 (20×20 AM32 4-in-1) | Rev 2 ordered |
| RX | **OpenRX-Lite** (ESP32-C3 + SX1281 ELRS 2.4 GHz) | All variants finalized |

## Status — design in progress, no hardware yet

Schematic sources were refreshed in June 2026 from the current sibling revisions (replacing the original 2026-04 port from OpenFC-ECO V0.3 / 4in1ESC 2). Outstanding work before a first spin:

- Root-sheet wiring: hierarchical sheets are imported but inter-stage signal routing (FC↔ESC, FC↔RX) is not finalized
- Schematic re-annotation (reference collisions across merged sheets, 4× ESC channel instances)
- PCB layout: the layout in `OpenAIO.kicad_pcb` predates the refresh and will be redone
- Architecture: stacked two-board construction (FC top, ESC bottom, bonded via BGA-style solder pads, both outlines in one `.kicad_pcb`) — inherited decision, under review against a single-board layout

## Repository layout

```
OpenAIO/
├── README.md  LICENSE
├── docs/                          ← ALTERNATIVES.md, COST_ANALYSIS.md (ESC supply chain)
└── hardware/
    ├── OpenAIO.kicad_pro / .kicad_sch / .kicad_pcb
    ├── schematics/
    │   ├── fc/        rp2350a, power, imu, osd, blackbox, pads   (OpenFC-Lite-Mini rev2)
    │   ├── esc/       esc_channel (×4 from root), esc_main + ESC (reference)
    │   └── elrs/      elrs                                        (OpenRX-Lite)
    ├── lib.kicad_sym / lib.pretty / lib.3dshapes            ← FC library
    ├── components.kicad_sym / 4in1ESC.pretty / .3dshapes    ← ESC library
    ├── OpenRX-Shared.kicad_sym / .pretty / .3dshapes        ← RX library
    ├── sym-lib-table / fp-lib-table                         ← project-local entries only
    ├── datasheets/    FC/  ESC/  ELRS/
    └── production/    (generated by KiCad Fabrication Toolkit, gitignored)
```

All libraries are project-local. KiCad standard libraries (`Device:`, `power:`, `Connector:`, …) are the only external references. KiCad 10.

`esc_main.kicad_sch` is the 4in1-mini top sheet (buck, LDO, current sense, TVS, ESC connector) kept as reference circuitry — it is not instantiated by the root sheet. `ESC.kicad_sch` is a duplicate of `esc_channel.kicad_sch` that exists only so `esc_main`'s internal channel instances resolve if opened.

## Firmware targets

| Stage | Target |
|---|---|
| FC | Betaflight, derived from `OPENFC_LITE_MINI_RP2350A` (custom target, `MANUFACTURER_ID = OPFC`) — AIO needs its own resource map |
| ESC ×4 | AM32, AT32F421 target (flashed per channel) |
| RX | ExpressLRS `Unified_ESP32C3_2400_RX` (≥ 3.5.0) |

## Supply chain notes

See `docs/ALTERNATIVES.md` and `docs/COST_ANALYSIS.md`.

- **NSG2065Q**: footprint stays FD6288Q-compatible so the 6288Q clone family is drop-in
- **INA186A3IDCKR**: watch stock; INA199A2 fallback has 26 V common-mode — tight at 6S
